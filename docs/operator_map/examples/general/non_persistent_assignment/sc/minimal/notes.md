# Non-persistent assignment of a scalar

Authored from the text of [Non-persistent
assignment](https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/General%20purpose%20operators/Non-persistent%20assignment/index.html): "If the Operand `op` is a scalar
value, the result Data Set has no Components and contains only such a scalar value. For example,
`income := 3` assigns the value `3` to the non-persistent Data Set named `income`." The expected
output is the scalar 3, an integer.
