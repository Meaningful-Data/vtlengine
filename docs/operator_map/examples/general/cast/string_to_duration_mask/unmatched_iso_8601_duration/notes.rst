:Tests: ``cast(Me_1, duration, "P")`` on the String ``P1M``, an ISO 8601 duration of one month, which the one-character mask does not describe.
:Manual: `Type conversion <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/General%20purpose%20operators/Type%20conversion/index.html>`__: "if the input string or a part of it cannot be matched to the specified or default mask, an error is raised". Without a mask, "If the input string starts with ``P``, the entire string is consumed and parsed, according to the ISO-8601 standard for durations".
:Expected: The error ``2-1-5-3``, "Impossible to cast {value} from type {type_1} to {type_2} using mask {mask}.": the mask ``P`` is one period indicator, and ``P1M`` has three characters. Only the mask explains the error: without it, the conversion reads ``P1M`` as one month.
