:Expected: The error ``2-1-5-3``, "Impossible to cast {value} from type {type_1} to {type_2} using mask {mask}.", as the mask asks for a digit for ``+`` and one for ``D``, where a ``*`` in place of ``+`` would take none. Without the mask, ``7`` would give ``7``.
