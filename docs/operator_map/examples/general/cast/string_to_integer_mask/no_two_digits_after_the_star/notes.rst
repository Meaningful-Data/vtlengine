:Tests: ``cast(Me_1, integer, "*DD")`` on a String measure whose value, ``7``, has one digit, where the mask asks for any number of digits and then two.
:Manual: `Type Conversion and Formatting Mask <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/typical_behaviour.html#type-conversion-and-formatting-mask>`__: "“*” an arbitrary number of digits" and "“D” one numeric digit (for the mantissa of the scientific notation)"; `Type conversion <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/General%20purpose%20operators/Type%20conversion/index.html>`__: "if the input string or a part of it cannot be matched to the specified or default mask, an error is raised".
:Expected: The error ``2-1-5-3``, "Impossible to cast {value} from type {type_1} to {type_2} using mask {mask}.", as ``*`` may take no digit but the two ``D`` need two. A string that the mask matches gives what the conversion without a mask gives, so only a string that it refuses shows ``*``. Without the mask, ``7`` would give ``7``.
