# `cast("42", integer)` on a scalar

Authored for [Type conversion](https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/General%20purpose%20operators/Type%20conversion/index.html), whose operand may be a scalar. By the string to
integer rule ("a sequence of digits is consumed to determine its absolute value"), `"42"` gives
the integer 42.
