:Tests: ``cast(Me_1, time, "YYYY-MM-DD/PY\YM\MDD\D")`` on a String measure: the manual's mask for a time written with its "Start and duration", to the day.
:Manual: `Type Conversion and Formatting Mask <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/typical_behaviour.html#type-conversion-and-formatting-mask>`__: "Start and duration, such as "2015-03-03/P1Y2M10D"" with this mask, and "P designator of duration" among the "fixed characters used in the ISO 8601 standard which can appear as fixed characters in the relevant masks".
:Expected: ``2015-03-03/2016-05-13``, from the manual's value: a year, two months and ten days after the start. The mask writes its first ``P`` without the reverse slash that would keep it from being the special character "P period indicator": the example reads it as the fixed "P designator of duration", as the manual's value does. By the manual, the conversion without a mask, which parses ISO 8601 time intervals, reads this value as well: no value tells the mask apart.
:Finding: Both engines refuse the mask with SemanticError ``1-3-13``, "Unsupported VTL construct: a time written with a duration in the mask [...]".
