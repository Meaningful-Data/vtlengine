:Tests: ``cast(Me_1, string, "*DD")`` on an Integer measure: any number of digits, then two.
:Manual: `Type Conversion and Formatting Mask <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/typical_behaviour.html#type-conversion-and-formatting-mask>`__: "“*” an arbitrary number of digits" and "“D” one numeric digit (for the mantissa of the scientific notation)".
:Expected: ``07`` from ``7``, and ``12345``: the two ``D`` write the last two digits, with a leading zero for ``7``, which the conversion without a mask does not write, and ``*`` any digits before them, none for ``7`` and ``123`` for ``12345``, which the two ``D`` alone have no room for. The mask starts with ``*``: ``D*``, as in the manual's ``D*.D*``, may be read as a ``D`` and then any digits, or as any number of ``D``, which differ on a value of one digit.
