:Tests: ``cast(Me_1, time_period, "YYYY\QQ")`` on the String ``2000-Q1``, which has a ``-`` that the mask does not have.
:Manual: `Type conversion <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/General%20purpose%20operators/Type%20conversion/index.html>`__: "if the input string or a part of it cannot be matched to the specified or default mask, an error is raised". Without a mask, "a ``-`` is consumed if present" after the year, and the page's Example 9 reads ``2000-Q1`` with the mask ``"YYYY-\QQ"``.
:Expected: The error ``2-1-5-3``, "Impossible to cast {value} from type {type_1} to {type_2} using mask {mask}.": after the year, the mask has the letter ``Q`` where the string has a ``-``. Only the mask explains the error: without it, the conversion reads ``2000-Q1`` as the first quarter of 2000.
