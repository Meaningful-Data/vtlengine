# Parentheses on scalars

Authored from the text of [Parentheses](https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/General%20purpose%20operators/Parentheses/index.html): "For example `(2+3)*4`
returns `20`, instead `2+3*4` returns `14` because the multiplication has higher precedence than
the addition." The operands are integers, so the result is the integer 20.
