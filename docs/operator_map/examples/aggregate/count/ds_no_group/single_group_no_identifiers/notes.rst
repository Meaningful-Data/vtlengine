:Tests: ``count`` with no grouping clause, over the shared input with two Number measures and no null.
:Manual: `Aggregate invocation <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/Aggregate%20and%20Analytic%20operators/Aggregate%20invocation/index.html>`__: "If the grouping clause is omitted, then all the input Data Points are aggregated in a single group and the clause returns a Data Set that contains a single Data Point and has no Identifiers."
:Expected: one data point with no identifiers, with ``int_var`` = 6, the number of data points.
:Team decision: `#1049 <https://github.com/Meaningful-Data/vtlengine/issues/1049>`__: over a data set, ``count`` gives one Integer measure ``int_var`` whatever the measures of the operand, and ignores the data points whose measures are all null. With two measures, this settles the conflict between the count page's ``int_var`` and the Aggregate invocation's "the resulting Data Set has the same Measures as the operand".
