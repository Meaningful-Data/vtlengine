:Tests: ``count`` with ``group except Id_2``: the data points are grouped by ``Id_1``, the identifier that it does not name.
:Manual: `Aggregate invocation <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/Aggregate%20and%20Analytic%20operators/Aggregate%20invocation/index.html>`__: "group except: the Data Points are grouped by the values of the Identifiers not specified as groupingId. The Identifiers specified as groupingId are dropped in the result."
:Expected: ``Id_1`` and ``int_var``, without ``Id_2``: 4 for ``A`` and 2 for ``B``, the number of data points of each group.
:Team decision: `#1049 <https://github.com/Meaningful-Data/vtlengine/issues/1049>`__: over a data set, ``count`` gives one Integer measure ``int_var`` whatever the measures of the operand, and ignores the data points whose measures are all null. With two measures, this settles the conflict between the count page's ``int_var`` and the Aggregate invocation's "the resulting Data Set has the same Measures as the operand".
