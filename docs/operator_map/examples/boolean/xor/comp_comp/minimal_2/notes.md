Three-valued logic: every data point has a null operand, on the left in rows 1 and 4 and on the
right in rows 2 and 3.

The page lists `false xor null`, `true xor null` and `null xor null` as null. The operator is
symmetric, so a null operand on the left gives null as well.

| Id_1 | Me_1 | Me_2 | Me_3 = Me_1 xor Me_2 |
|---|---|---|---|
| 1 | null | false | null |
| 2 | true | null | null |
| 3 | false | null | null |
| 4 | null | true | null |
