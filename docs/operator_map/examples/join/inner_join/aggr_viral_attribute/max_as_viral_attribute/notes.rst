:Manual: `Inner Join <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/Join%20operators/Inner%20Join/index.html>`__: the role of an aggregated component is ``aggrRole ::= { measure | attribute | viral attribute }``, and "if omitted, the Measure role is assumed"; on viral attributes, "if the aggr clause is present, the Attribute propagation rule is again applied to the set of all values that are aggregated".
