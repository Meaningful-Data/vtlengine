# full_join: aggr_group_by (minimal_2)

Authored. The `aggr` clause takes the largest `At_1`, a Viral Attribute of `DS_1`, by `Id_1`, under its own name and with the role left out.

Inputs: `DS_1` has the identifiers `Id_1`, `Id_2`, the measure `Me_1` and the **Viral Attribute**
`At_1`; `DS_2` has the same identifiers and the measure `Me_2`. `(2,B)` is in `DS_1` only, and
every key of `DS_2` is in `DS_1`.

| Id_1 | Id_2 | DS_1 Me_1 | DS_1 At_1 | DS_2 Me_2 |
|---|---|---|---|---|
| 1 | A | 10 | a | 1 |
| 1 | B | 20 | b | 2 |
| 2 | A | 30 | c | 3 |
| 2 | B | 40 | d | |

The attribute is viral because this page's VDS₁ holds only the identifiers, the measures and
"The viral attributes, coming from any number of Data Sets, which appear once": a plain attribute
would not reach the clause. "Viral attributes, present in exactly one input data set, are also kept
unchanged in VDS₁." The full outer join keeps the four keys of `DS_1`, with `Me_2` null at `(2,B)`.
`DS_2` has no key of its own, so no data point lacks `DS_1`'s `At_1` (the page does not say what
it would hold there).

The join page: "**aggr** aggregates values of non-identifier components by indipendent sub-expressions evaluated at component level. The role of the components can be specified, so the original role can be changed if the name is kept the same; if the role is not specified, it will be **measure**. All non-identifier components are removed, and only the components generated by the sub-expressions are kept". So `At_1` is a Measure in the result. Outside a join, the Aggregation clause page gives the opposite default: "if the component exists in the operand Data Set then it maintains its role". On viral attributes this page says "if the **aggr** clause is present, the Attribute propagation rule is again applied to the set of all values that are aggregated". I read that sentence as being about the viral attributes the clause does not compute: here `At_1` is computed under its own name, and the role sentence above lets the generated component change the role. With **group by** the identifiers not named are dropped. `max` on a String gives a String (Maximum value: "For other comparable scalar types (for example **time**, **string**, **boolean**), the result has the same type as the operand"). `Id_1` = 1 groups `At_1` {a, b} and `Id_1` = 2 groups {c, d}.

| Id_1 | At_1 |
|---|---|
| 1 | b |
| 2 | d |
