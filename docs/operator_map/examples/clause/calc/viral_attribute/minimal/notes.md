# calc viral attribute

The same calculation as the manual's `ex_2` (`calc attribute At_1 := "EP"`), with the role
`viral attribute`: the new component `At_1` is a Viral Attribute holding `"EP"` on every data
point. The manual: "The keyword **viral** allows controlling the virality of the calculated
Attributes". `calc` combines no data points, so no propagation rule is involved: the attribute
is only created.
