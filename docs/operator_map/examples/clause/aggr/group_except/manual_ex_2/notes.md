# Aggregation ex_2: type of the min

`Me_3 = min(Me_1)` stays an Integer, as the manual's `ex_2.json` writes it: unlike `sum`, `min`
allows no alternative type. `Me_1` is an Integer, and the Minimum value page says:
"For numeric operands, the result has the **same** type as the operand (**integer** or **number**)".
