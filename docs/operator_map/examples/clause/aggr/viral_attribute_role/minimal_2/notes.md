# aggr with only a viral attribute

The same aggregation as `attribute_role/minimal_2`, with the role `viral attribute`. The result
holds `Id_1` and the Viral Attribute `At_1 = max(Me_1)`: 5 and 4. It has no Measure, which the
User Manual allows ("A Data Set without Measures is allowed"). `DS_1` has no Attribute of its
own, so no propagation rule is involved.
