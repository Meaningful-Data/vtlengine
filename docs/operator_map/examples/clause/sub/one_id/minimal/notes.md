# sub on one Identifier

The manual's procedure: keep the data points with `Id_1 = 1` (`(1, A, 10)` and `(1, B, 20)`),
eliminate the others (`(2, A, 30)`), then project out `Id_1`. The result has the Identifier
`Id_2` and the Measure `Me_1` of `DS_1`. The manual's example for one Identifier (`ex_3`) adds
two subspaces with `+`; this one shows `sub` alone.
