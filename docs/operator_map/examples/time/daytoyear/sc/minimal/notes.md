Manual: [Number days to duration](https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/Time%20operators/Number%20days%20to%20duration/index.html), Example 2 (in the text of the page):
`daytoyear (782);` "returns P2Y52D". "The operator **daytoyear** returns a duration having the
following mask: \PY\YDDD\D", the number of years and days "according to ISO 8601 Y = 365D":
782 = 2 × 365 + 52.
