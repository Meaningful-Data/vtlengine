Manual: [Number days to duration](https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/Time%20operators/Number%20days%20to%20duration/index.html), Example 3 (in the text of the page):
`daytomonth (134);` "returns P4M14D". "The operator **daytomonth** returns a duration having the
following mask: \PM\MDD\D", the number of months and days "according to ISO 8601 M = 30D":
134 = 4 × 30 + 14.
