:Tests: ``stock_to_flow(DS_1)`` on annual series whose reference time identifier is a *time*.
:Manual: `Stock to flow <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/Time%20operators/Stock%20to%20flow/index.html>`__, Example 1: the operator "calculates the corresponding flow data by subtracting from the measure values of each regular period the corresponding measure values of the previous one."
:Expected: The manual's values: ``A`` 2.0, 5.0, -3.0, 9.0 and ``B`` 4.0, -8.0, 0.0, 6.0, a Number ``Me_1``.
:Erratum: The manual's input structure declares ``Me_1`` as String, but the operand's measures are ``measure<number>``, the values are numbers, and the manual's output and its ``DS_2`` to ``DS_4`` have a Number ``Me_1``: the input ``Me_1`` is Number.
:Adaptation: The page writes its *time* values in "the time format YYYY-MM/YYYY-MM", as ``2010M1/2010M12``, which vtlengine cannot load (DataLoadError ``0-3-1-6`` on both engines). Each ``YYYYM1/YYYYM12`` of the input and the output is written ``YYYY-01-01/YYYY-12-31``, the same interval in the ``YYYY-MM-DD/YYYY-MM-DD`` form of the manual's "Behaviour of Time operators" and of ``docs/data_types.rst``; nothing else changes.
