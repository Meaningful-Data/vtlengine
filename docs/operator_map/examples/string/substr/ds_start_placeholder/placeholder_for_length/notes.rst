:Tests: the placeholder ``_`` for ``length``: ``substr(DS_1, 2, _)`` is ``substr(DS_1, 2)`` with the underscore written out.
:Manual: In the invocation, a non-specified optional operand "is substituted by an underscore or, if it is in the end of the invocation, can be omitted" (Overview and conventions, syntax conventions); `Sub-string extraction <https://sdmx-twg.github.io/vtl/v2.2/reference_manual/operators/String%20operators/Sub-string%20extraction/index.html>`__: "If ``length`` is omitted or overcomes the length of the input string, the substring ends at the end of the input string."
:Expected: each value loses its first character: ``hello`` gives ``ello`` and ``ab`` gives ``b``. A null operand gives a null result: "most of the scalar operations (arithmetic, logical, and others) return null when any of their arguments is null" (User Manual), as the manual's ``length`` and ``instr`` examples show.
