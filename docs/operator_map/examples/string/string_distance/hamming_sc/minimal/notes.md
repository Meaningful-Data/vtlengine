The Hamming distance "is the number of positions at which the corresponding characters are
different" and both strings must have the same length (String distances). `"karolin"` and
`"kathrin"` have 7 characters and differ at positions 3 (`r` and `t`), 4 (`o` and `h`) and 5
(`l` and `r`); the others are equal, so the distance is 3. The result type is number.
